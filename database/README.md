# 数据库目录说明

## 当前状态

当前 API 已先使用 `data/home-config.json` 作为首页配置的持久化存储。

这样做的目的是：

- 当前不依赖额外安装数据库驱动
- 服务重启后首页配置不丢失
- 接口层和服务层已经按后续数据库接入方式拆开

## MySQL 初始化

初始化脚本：

- `mysql/init.sql`

当前脚本已准备：

- 数据库 `blitz_of_pi`
- 配置表 `system_configs`
- 首页配置初始数据

## 后续切换计划

后续正式接入 MySQL 时，建议顺序：

1. 安装数据库驱动
2. 增加数据库连接层
3. 将 `home-config.repository` 从文件仓储切到 MySQL 仓储
4. 保持控制器和服务层接口不变
